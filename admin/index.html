Migration status

Poster Control is fully GitHub-hosted. PC Control and Vouchers now use a reusable server adapter so they no longer depend on ChatGPT. The existing rental backend remains the authority for PC time and one-use voucher redemption.
Expected admin API: GET /api/admin/pcs, POST /api/admin/pcs/{id}/time, POST /api/admin/pcs/{id}/lock, POST /api/admin/pcs/{id}/maintenance, GET /api/admin/vouchers, and POST /api/admin/vouchers. If your existing backend uses different routes, only this adapter needs to be changed.
